## `01 / О проекте`

**KairoKit** — развивающийся персональный аниме-трекер. Проект создаётся как удобное пространство для собственной коллекции, наблюдения за прогрессом и сохранения истории просмотра.

В основе — простой принцип: **основные возможности должны оставаться доступными без обязательной оплаты**. В дальнейшем могут появиться необязательные платные элементы персонализации и дополнительные функции.

> [!NOTE]
> KairoKit находится в разработке. Возможности, интерфейс и структура проекта могут изменяться.

## `03 / Подход к развитию`

- **Основной функционал — бесплатно.** Без обязательной подписки ради базового учёта аниме.
- **Персонализация — по желанию.** Дополнительные элементы оформления и выделения профиля могут появиться позднее.
- **Социальные возможности — в планах.** Активность, рейтинги и таблицы лидеров рассматриваются как будущие направления, а не уже доступные функции.
- **Мобильное приложение — возможный следующий этап.** Первой платформой рассматривается Android.
